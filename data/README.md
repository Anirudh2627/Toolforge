# data/

Generated artifacts live here. Nothing in this directory is required to be
committed; everything is reproducible from code.

- `tasks/benchmark_v1.jsonl` — the task benchmark. Regenerate with:
  `python scripts/generate_tasks.py --out data/tasks/benchmark_v1.jsonl`
- `tasks/benchmark_v1_summary.json` — category / family / split counts.
- `trajectories/` — collected trajectories (JSONL) + `_stats.json` sidecars
  (rejection rates, failure categories, coverage). Regenerate with:
  `python scripts/generate_trajectories.py --source reference`
- `sft/` — tokenizer-free SFT records (`sft_train.jsonl`, `sft_val.jsonl`,
  `sft_stats.json`): message-level samples ready for tokenization inside
  `scripts/train_sft.py`. Regenerate with `scripts/prepare_sft_data.py`.

Split rules are enforced by the pipeline: trajectory collection refuses
`test`-split tasks, and SFT mixing refuses test-split and held-out-family
(`crm`) trajectories.
